# Comparison playbook

Use this when the viewer must choose between options, tools, approaches, or tradeoffs.

## Required shape

- Use aligned option cards with the same fields in the same order so comparison happens vertically and horizontally, not by hunting.
- Make cost as visible as benefit. Every card must show the downside, migration cost, risk, or constraint with equal visual weight.
- Add a clear recommendation only after the evidence is visible.
- Keep decision-relevant attributes aligned: price with price, risk with risk, implementation effort with implementation effort.

## Pattern

1. One-sentence decision context.
2. Three to five cards max, each with: best for, benefits, costs/risks, implementation effort, and confidence.
3. A highlighted decision row or recommendation footer.
4. If the choice depends on viewer preference, pair this with the `input` playbook.

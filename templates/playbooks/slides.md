# Slides playbook

Use this when the content is a sequential narrative meant to be stepped through, taught live, or reviewed one beat at a time.

## Required shape

- One idea per slide. If a slide needs "and also," split it.
- Use large type and short lines so it works from across the room and in screenshots.
- Add keyboard navigation: ArrowRight/Space advances; ArrowLeft goes back; Home/End jump.
- Use progressive disclosure for lists, diagrams, and examples so attention lands on the current point.
- Show progress and current slide title.

## Pattern

- Opening slide: promise and context.
- Middle slides: one point, one visual, one implication.
- Final slide: decision, recap, or requested action.

Keep the deck portable: no build step, no external router, and no fragile viewport assumptions.
